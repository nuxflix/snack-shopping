# Color roles

Snack Shopping uses its own palette on top of the system font, the way Jetsnack keeps a custom color system beside Material type.

| Role | Value | Where it shows |
| --- | --- | --- |
| Paper | `#FBF7F8` | Screen background |
| Ink | `#24162F` | Titles, unselected tabs |
| Coral | `#FF6A58` | Price eyebrows, text buttons |
| Violet | `#7C4DFF` | End of the shop gradient |
| Gradient | coral, through pink, to violet | Featured snack, primary buttons, selected tab |

Titles use the system serif. Body text uses the system sans. The selected tab grows into a gradient capsule; the others stay ink circles.
